# Tai Chi Facile

Web app installabile (PWA) per routine guidate di Tai Chi semplici e adatte ai principianti.

## Funzioni
- Sei routine da 5 a 15 minuti
- Modalità in piedi e da seduti
- Timer, animazioni e guida vocale in italiano
- Pausa, movimento precedente/successivo
- Progressi, minuti, serie di giorni e traguardi
- Uso offline dopo il primo caricamento
- Dati salvati solo nel browser con localStorage

## Pubblicazione su GitHub Pages
1. Crea un nuovo repository pubblico.
2. Carica nella cartella principale tutti i file e la cartella `icons`.
3. Apri **Settings > Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona il branch `main` e la cartella `/root`, quindi salva.

## Nota
Per funzionare come PWA e usare il service worker, l'app deve essere aperta via HTTPS o localhost, non direttamente come file locale.
